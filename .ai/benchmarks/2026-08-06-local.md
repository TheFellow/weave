# Local graph microbenchmark baseline

Environment and exact results are recorded by:

```sh
go test ./internal/storage -run '^$' -bench BenchmarkIndexedGraph -benchmem -count 5
```

The fixture contains one compilation unit, one document, 2,000 symbols, and
1,999 call edges. It deliberately separates bounded query startup from the
unbounded diagnostic export path. Results below are a development-machine
baseline, not a service-level guarantee; repository-scale measurements listed
in the vision remain future work.

<!-- benchmark-results -->

Measured on `darwin/amd64`, Intel Core i5-1038NG7, Go 1.25.0, three runs:

| Operation | Time/op range | Bytes/op | Allocs/op |
| --- | ---: | ---: | ---: |
| Prefix lookup, limit 50 | 0.81–1.12 ms | 333,210 | 4,679 |
| One-kind outgoing adjacency | 15.2–18.7 µs | 7,384 | 86 |
| Complete deterministic export | 6.31–9.88 ms | 4,885,277 | 44,695 |

The prefix query is comfortably interactive but allocation-heavy enough to
track. Export appropriately costs much more because its contract materializes
and sorts the complete graph. Future baselines should compare changes with
`benchstat` and add the four real repositories named in the vision.
